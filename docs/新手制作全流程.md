# 万灵漫剧新手教程：从全文到生产包或 MP4

旧版已有剧本：进入“Agent 任务”，展开“已有剧本待核对”查看每集缺项。已有剧本会继续保留；补齐完整原文阅读、高光报告与原文逐字依据，核对通过后锁定现有稿。可导入已有高光报告或让接手 Agent 根据实际完整阅读补写；只有使用软件收费模型生成时才需要本次文本生成额度，不因升级重做整部剧本。

模型切换后，“最近模型请求”显示实际提交模型和 HTTP 状态；“上次执行失败”显示历史失败的模型与时间。切换不会改写历史请求。让 Agent 重新读取当前 context 后继续原有进度，不能把旧失败记录当作新请求的结果。

模型选择（v0.4.22）：软件设置的“默认生成模型”用于新项目。已有项目进入项目概览，展开“本项目生成模型”选择文本、图片、视频模型；或在 Agent 准备检查点击“本项目改用…”。Agent 检查展示本项目实际提交使用的模型，保存默认值不会自动改写已有项目。

适用于 v0.4.15 起。此教程随软件签名自动更新；设置 → 交给 Agent 制作 → 下载最新版教程。旧安装目录内历史教程副本可能停留在原版本，请使用此入口。技能 ZIP 也包含当前教程，外部客户端已导入的技能请重新下载导入。

第一次先做一集短内容。软件会串联制作步骤，需要你确认费用、剧情和生成结果时会停下来；照着当前步骤的提示处理，再继续即可。

## 1. 打开软件

完整解压软件包，不要只拿出其中一个文件。双击“启动试用.cmd”，等待浏览器自动打开软件。

首次会创建桌面“万灵漫剧”快捷方式，以后双击桌面图标即可。启动窗口要保留，最小化就行；关闭它会停止本机服务。

先打开首页“演示项目 · 从文字到成片”，播放样片，再点“查看制作画布”。看示例不需要密钥，也不会扣生成费用。

## 2. 填自己的密钥

左上角“设置” → “登录木木 API”。在官网登录后点“同步余额到万灵漫剧”，回到软件能看到余额。

然后点“管理密钥”，创建并复制 API 令牌。回到软件，把它粘贴到“API Key”输入框，点“更新并读取模型”。只登录账户还不能生成内容，必须保存自己的密钥。

登录网址：https://api.mumugofe.com/login
密钥管理：https://api.mumugofe.com/console/token

三个默认模型已预置，第一次可以直接沿用，不用自己寻找模型。生成文本、图片和视频会消耗额度，每一步确认前看清数量和费用。

## 3. 新建自己的项目

点左侧“＋ 新建项目”，填写项目名。首次从小说或完整剧本开始，可以选择“常规漫剧”。

在“项目概览”展开“项目画面设置”，先确定画面风格和比例。做手机竖屏内容选竖屏，做横屏内容选横屏；生成图片和视频前先保存设置。

## 4. 保存全文并建立分集

点“原文自动分集” → 粘贴完整小说或剧本，也可以选择 UTF-8 TXT → 点“保存完整原文”。看到“已保存完整原文”再往下操作。

第一次将“每集原文章节数”保持为 1，点“按章节预览”。检查标题和内容范围，没问题后点“确认并生成这些分集”。这个按章节预览步骤不调用模型。

如果没有识别出章节标题，会先保留为完整的一集；可以整理原文中的章节标题后重新保存、预览，也可使用页面里的文本模型分集建议并确认其费用。不要把一整本书误当作适合直接生成的一条短视频。

已有分集后项目全文会锁定，不能直接替换。每集仍可以拆成多个视频片段。

## 5. 进入第一集，启动自动流程

回到“项目概览”，打开第一集或点“继续制作”，进入“制作画布”。点顶部“生成任务”，找到“Agent 制作流程”。

先选择“本次交付”：默认继承项目规则，新项目默认“分镜生产包”；选择“MP4 成片与剪映草稿”才会进入视频制作。生产包的视频提交额度固定为零，导出生产包后结束。已有流程沿用启动时的目标，切换目标须先取消原流程再启动。

按自己的需求填写文本、图片，以及成片模式下的视频提交次数上限，点“启动本集流程”。这里填写的是最多请求多少次，不是积分或金额上限；不同模型与实际文本用量的价格不同，失败或结果未知的已提交请求也占用次数，先找回原任务。流程从本集已有进度继续。

接下来只需要认识两种提示：

- **待预算确认**：打开“查看本步实际输入”，核对内容、模型、数量和价格，勾选确认，再点“确认预算并执行本步”。
- **待核对**：点“前往原有页面处理”，完成当前页面的确认，再回到“生成任务”点“检查并继续”。

## 6. 核对原文、高光和正式剧本

进入“原文与高光”，读完本集原文后点“我已完整阅读”。模型生成报告后，展开建议，核对内容，点“采用为可编辑报告”，然后“确认报告”；自行改动后先保存报告。

进入“正式剧本”，展开模型建议，核对事件、人物反应、对白和内心 OS，点“采用为可编辑剧本”。修改了剧情节点，先点该节点的“保存节点”。最后点“锁定正式剧本并建立画布”。

锁定后先完成“原文覆盖”核对：逐节点确认原文范围、高光覆盖、事件因果、人物反应、对白/OS与可见信息。模型建议仅为待核对候选，不能直接代替确认；记录过期时重新核对。核对完成再提取人物、场景和道具或付费出图。锁定正式剧本是下游唯一剧情依据，不得为参考图或字数删改剧情。

## 7. 核对人物、场景和道具

流程提取资产后，在“资产与状态”采用建议，检查名字、外观和剧情状态是否正确。

新人物先生成“三视图＋大头照”：横向一排四个等宽格，依次为正面完整全身、90°侧面完整全身、背面完整全身、正面大头近照。第四格头部占本格至少60%，四格必须同一张脸、发型、衣着、配色和当前形态。蛇形角色用蛇头近照；不露正脸的第一人称资产沿用原规则。

放大实际审查设定图，确认正面、侧面、背面和大头照属于同一角色，服装与当前剧情状态一致。审图通过后直接选用完整四视图作为片段参考，整张传给视频模型，用全部视角锁定同一人物。人物生成、导入、返修和新绑定均统一使用整张四视图；独立全身照、独立头图及裁切入口已移除。提示词说明多个视角都是同一角色，不把拼图版式演成剧情场景。

已核验的整张旧四视图可补记布局后直接使用，不要求面板等宽，不裁切原图。

旧独立照片和裁图仅保留为历史记录；后续制作先补选已审完整四视图，不自动补跑付费任务。剧情状态的四视图沿用已审基础身份参考，保持人物身份并遵循当前服装、健康和伤势。

少了人物、场景或道具，点顶部“＋ 新增资产”。图片局部不满意，在“资产与状态”的该图片上点“以此图返修”，填写“保留哪些正确部分、只修哪些错误”；候选面板也能选择“返修原图”。预览会列出实际原图ID、文件指纹和用途，确认费用后才生成。模型会同时接收原图和修改要求；废图只能继承明确正确部分。新图需要实际审图和明确选用，旧图保留。原图或其他参考在确认后变化时，提交会被拦住，重新预览后再决定是否生成。

## 8. 核对分镜，准备生产包或视频

按流程查看每个片段的分镜建议，采用后逐镜核对动作、顺序和时长，点“逐镜核对完成，确认分镜”。检查最终提示词和参考图，再按提示完成“五层无损核对”放行。

生产包模式完成当前版本五层核对后，会停在“导出分镜生产包”，确认导出后结束。成片模式才会准备首个视频：确认输入和费用后生成，播放并听完逐句检查；通过后明确选用，并完成页面要求的审片与“试片放行”，再继续生成后续片段。

技术检查使用 FFprobe/FFmpeg 检查时长、分辨率、有无音轨、黑帧及静止风险；不能核验角色表演、台词内容、声音或口型。内置 Agent 目前无法直接听看视频，必须等待实际审片，不能拿技术检查通过替代内容确认。

视频不满意，可以生成另一个候选版本，对比后再选用。出现“结果未知”时，先查询或找回原任务，不要连续重复点击生成。

## 9. 合成并下载 MP4

所有片段完成后，进入“剪映导出”，查看“正式成片导出预检”。有待处理项，就按提示回到对应页面补齐：资产绑定、文件检查、审片、五层核对或高光预告选择。

第一次想先导出纯正片，在“本集高光预告”选择“不加入”，再点“保存本集规则”。不用真实超分时，保持超分选项不勾选。

预检通过后点“合成并导出 MP4”，等完成，再点“下载 MP4”。软件会按片段顺序合成并保留原声。走 Agent 流程时，最后勾选导出确认，点“确认并导出”即可；完成后同样在导出页查看、下载。

如果还想加字幕、音乐或精剪，可以另存剪映草稿，进入剪映继续编辑。

## 10. 下次继续与问题反馈

下次双击桌面“万灵漫剧”，打开原项目即可继续。项目保存在软件目录的 runtime 文件夹；移动软件或更新程序时保留它。

遇到“Failed to fetch”或“无法连接本机服务”：先保留输入框里的全文，复制到 TXT 备份，不要直接刷新；通过桌面快捷方式重新启动软件，确认启动窗口还在，再进入项目核对是否已经保存。新版保存失败会保留输入，并提供“下载全文备份”。

若仍报错，请提供“点击了哪个按钮＋报错截图＋全文大约多少字”，启动窗口有错误时一并截图。用包内联系二维码反馈，不要发送密钥。

操作顺序：**启动 → 填密钥 → 新建项目 → 设置画面 → 保存全文 → 建立分集 → 启动流程 → 确认费用与内容 → 审图审片 → 导出 MP4**。
