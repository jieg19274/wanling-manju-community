# 万灵漫剧 · Windows x64 免安装候选

联系与反馈见包内“联系与反馈.md”；也可直接打开“微信联系二维码.jpg”扫码添加好友。

本包已内置 Node.js 24.21.0、FFmpeg 8.1.1、FFprobe 和图片处理运行库，无需另装 Node.js、FFmpeg 或执行 npm 安装。必须保留整个文件夹，尤其是 tools 和 node_modules。

1. 完整解压到可写目录，双击“启动试用.cmd”。启动脚本直接使用 tools/node/node.exe，视频工具优先使用 tools/ffmpeg/bin。
2. 首次启动会自动创建桌面“万灵漫剧”快捷方式，软件就绪后会自动打开默认浏览器显示界面。保留启动窗口。首页可播放“演示项目 · 从文字到成片”，进入画布查看原文、资产、分镜及视频。
3. 查看示例无需密钥。制作自己的内容时，按“功能使用说明.md”连接账户并保存自己的密钥。文本、图片和视频三个已验证模型已预置。
4. 退出时关闭启动窗口。项目和设置保存在本包 runtime 文件夹。移动软件时一并保留该目录，桌面快捷方式需重新创建。

以后直接双击桌面“万灵漫剧”图标。启动窗口会最小化，就绪后自动显示软件；重复点击直接打开现有界面。关闭浏览器不会停止软件，退出时关闭最小化的启动窗口。移动软件文件夹后，先在新目录双击“启动试用.cmd”，会更新桌面快捷方式。也可用“创建桌面快捷方式.cmd”手动创建。

启动只调整本次进程的工具路径，不修改系统 PATH，不安装服务或开机任务；端口被其它程序占用时会停止并提示。真实超分另需 Real-ESRGAN，本包未内置。
