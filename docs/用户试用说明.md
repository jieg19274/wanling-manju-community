# 万灵漫剧 · 本地用户试用版

第一次制作请先看包内“新手制作全流程.md”，按顺序操作即可；本说明用于查具体功能。

联系与反馈见包内“联系与反馈.md”；也可直接打开“微信联系二维码.jpg”扫码添加好友。

这是 Windows x64 本地单用户依赖安装型试用包。Node.js 24、FFmpeg 和 sharp/libvips 等运行依赖由使用者独立安装，准备步骤见“安装与验收.md”。包型与运行时内置情况以 package-manifest.json 的 packageKind、bundledRuntime 字段为准。真实超分仍需另配 Real-ESRGAN，不会自动下载模型或调用收费超分服务。

内置风格预览图片由项目制作人使用 AI 重新生成，特效描述为项目制作人委托编写；制作人已明确授权随软件提供给用户使用。包内另有公开宣传演示项目和样片，可供查看制作过程；不含制作人的账户、密钥、私人项目、账本或付费授权。

解压或复制整个文件夹，先按安装说明准备依赖，再双击“启动试用.cmd”。启动完成后会自动用默认浏览器打开软件界面 http://127.0.0.1:5780/ ，保留启动窗口。首次创建独立 runtime 目录并加入“演示项目 · 从文字到成片”，直接播放首页演示样片或进入制作画布。退出请关闭启动窗口；不安装服务或开机任务。其它程序占用端口时会明确停止，不杀其它程序。

文本、图片和视频的默认模型已预置：`claude-opus-5-5`、`gpt-image-2.5-sunburst`、`专享sd2.5(30图10音/4-30秒/720p)`。看示例不需要密钥；制作新内容时在设置中填写自己的密钥。生图和视频不是免费，先检查模型、数量、实际输入和费用提示，再确认。价格未知不得当成确定报价。不要将本版监听到公网；它没有多用户账号和远程权限隔离。

## 木木 API 登录与添加密钥

默认 API 地址：`https://api.mumugofe.com/v1`。登录网址：[木木 API 登录](https://api.mumugofe.com/login)，密钥管理：[API 令牌](https://api.mumugofe.com/console/token)，账户余额：[余额与充值](https://api.mumugofe.com/console/topup)。设置页上方提供网页登录和密钥管理入口。余额直接显示在设置页，不需要再打开余额网页。

1. 打开软件左上角“设置”，点击“登录木木 API”。软件会打开木木官网的余额同步页面；已有网页登录会话时直接显示当前账户，否则在官网完成登录、安全验证后回到同步页面。点击“同步余额到万灵漫剧”，浏览器会自动回到软件。
2. 在平台“API 令牌”页创建密钥，按自己的使用需求设置分组、额度、到期时间及模型权限；复制新密钥。
3. 回到万灵漫剧，在“木木工坊 API”的 API Key 输入框粘贴密钥，点击“更新并读取模型”。密钥保存在当前 Windows 用户的本机加密配置中，不随试用包提供。
4. 三个默认模型已预置，可直接使用或改选。新项目自动继承默认值；已有项目进入项目概览的“本项目生成模型”逐项选择，或在 Agent 准备检查点击“本项目改用…”。面板显示实际提交使用的模型。
5. 授权完成后账户余额会自动显示；平时每 30 秒、返回软件窗口及任务状态变化时更新。也可以点击“刷新余额与价格”。文本显示输入、输出单价，图片显示每张价格，视频显示每段或每秒价格。页面不展示供应商模型描述、成本或涨价说明。未知分组可能显示价格区间，文本费用按实际用量结算，复杂价格条件无法安全计算时显示“暂无价格”。

余额来自木木网页登录账户的实时钱包接口。网页只回传一次性授权码，软件仅获得读取名称和余额的授权，不会获得密码、支付或账户管理权限；授权加密保存在当前 Windows 用户下。软件中的“取消连接”会撤销这份授权，木木网页仍保持登录；官网登录失效后需重新连接。登录账户与生成密钥属于不同账户时会明确提示，该钱包余额不会用于生成预算校验。有限密钥限制收在“密钥限额”中，不重复列出两份余额；不限额密钥不表示钱包余额无限。密钥无法解密时需重新填写并保存，原密钥不会被自动覆盖。

桌面快捷方式：首次双击“启动试用.cmd”，会自动创建使用软件图标的桌面快捷方式并打开界面。之后双击桌面“万灵漫剧”，启动窗口会最小化，软件就绪后自动打开界面，无需手动输入地址。重复点击会打开同一份软件的现有界面，不再启动第二个服务。移动软件文件夹后，先双击新目录的“启动试用.cmd”更新快捷方式；也可用“创建桌面快捷方式.cmd”手动创建。关闭浏览器页面不会停止服务；退出软件请关闭最小化的启动窗口。

制作主入口是内置 Infinite Canvas：空白拖动平移，滚轮缩放；H 移动，V 框选，Shift 多选；Ctrl+A 选择可见节点，Ctrl+Z 撤销布局，Ctrl+Shift+Z 重做，F 适应全部，Shift+F 聚焦选中。节点右下角调整大小；搜索列表定位；图片与视频可大窗预览。画布按本集资产展开，历史版本仍保留。下文说明具体操作。

图片和视频节点可就地打开候选工作台，再生成1–4版、比较、审图/审片后明确选用。新候选不自动换当前版本。失败先检查错误及费用；“准备单版重试”只预览新的确认，不自动收费。结果未知须用原确认号查回，不重复生成。资产换图需查看具体受影响片段，不自动批量重出。

单击资产图片、节点标题或正文直接放大查看；左侧元素列表或浮动工具条“信息”打开节点操作，视频播放器单击播放、双击预览。新增框用顶部“＋ 新增资产”：选择人物、场景或道具，填名称与描述，创建后出现在当前画布；可加入资产库中已有的资产。重做图片先选状态与图片用途，填写节点生成要求和数量，再核对生成输入与费用并确认；新图审图通过后“预览换图影响并选用”。“修改资产描述 / 状态”直接打开所选资产设置。新框尚未绑定片段，核对参考图后从右侧端口拖线到片段。

底部工具条、“更多”或右键菜单提供文本、图片和视频新增入口。图片入口打开人物、场景或道具资产创建窗口。文本能直接改名、编辑、调整字号，或“生图”创建项目资产并准备生成。新建视频工作节点为空，不关联已有片段，也不自动带入已有视频；在“信息”中关联片段后，仍须明确选择已有视频版本，或导入新视频。切换或清除关联片段会清空工作节点的视频绑定。工具条可复制、存资产、下载和移除；Delete移除，Ctrl+D复制，Ctrl+Z撤销。正式节点移除只隐藏画布，不删除原剧本和媒体。左侧“素材库”是当前集保存在本机浏览器的画布素材，顶部“资产库”是项目人物/场景/道具。工作节点关联和参考连线不自动改正式剧情或视频选用。

视频“大窗预览”读取同一个原媒体文件，显示真实尺寸；放大不会增加源分辨率。用“聚焦选中”检查单个节点，用“适应全部”找回全图。画布连线用于既有片段与候选版本关系，不允许把无关视频偷偷选给别的片段。

导出页显示草稿目录，精剪草稿保留未验收标记。核对当前片段版本、倍速、原声及超分选项；不把普通resize当真实超分，不添加用户未要求的字幕轨。新草稿另存，不覆盖已编辑草稿。剪映实际打开和声音内容仍需人工验收。

导出成功后，MP4 可在导出页直接预览、下载或复制成片路径；剪映草稿仍显示最近保存目录，可点击“复制草稿目录”；刷新后仍可定位。浏览器禁止剪贴板时可选中目录文本手动复制，不请求新的系统权限。

## 人工验收清单

1. 导入短剧本，按30秒分段；检查原对白、POV、声源和参考图用途。
2. 在同一画布框选两节点、拖动、缩放，刷新后核位置与连线；操作播放器不能移动画布。
3. 对现有候选比较并选用，核刷新后的选用状态。免费mock测试已覆盖幂等和恢复；个人付费测试由本人决定。
4. 使用现有视频另存剪映草稿，确认显示的目录、媒体和速度；实际打开剪映并听验。

已知限制：本次画布已完成浏览器操作验收，整集制作全链路仍需按人工验收清单核对。模型可能不遵守画面/声音提示，代码测试通过不等于成片合格。

## 新界面操作

完整原文保存成功会显示确认；中文按完整 UTF-8 请求读取。单次最多 700 万字符，UTF-8 TXT 最多 21 MB。保存失败时保留输入框全文，可点“下载全文备份”；重新启动本机服务后，先确认项目保存结果再继续，避免刷新丢失尚未保存的输入。

首页的“继续制作”进入当前剧集，分集列表可切换其它集。“项目画面设置”位于分集列表上方，展开后可修改原有风格与比例。“本项目生成模型”单独展开后可修改文本、图片、视频模型。项目页签按“项目概览 → 原文自动分集 → 资产与状态”排列。项目标题旁的垃圾桶将项目移入回收区，可在软件设置中恢复。操作成功提示会自动消失，也可手动关闭；错误和结果未知提示需处理或手动关闭。手机点左上角项目菜单进入项目和全局设置。

进入画布默认使用编辑模式，目前不提供“概览 / 编辑”切换。选中节点后点“信息”操作；点“放大查看”预览原图、视频或完整文本；复制、存本机素材、下载和移除在“更多”。重新生成资产图用“信息 → 生图 · 核对后生成”，接着核对输入和费用，满意后审图并选用新版本。手机制作导航的其余入口也收在顶部“更多”。

## Agent 接入现状

画布顶部“生成任务”内提供“Agent 制作流程”。先设置文本、图片和视频的提交次数上限，再点击“启动本集流程”。流程读取当前进度，依次准备高光报告、剧本候选、资产提取、参考图、分镜、完整提示词、首片与后续视频，最后合成 MP4 成片，并另存剪映草稿。不会覆盖锁稿、自动换图或选用新视频。

每个付费步骤先显示实际输入、API 报价或未知费用、密钥额度及最多提交次数；勾选确认后只执行本步。次数上限是硬限制，公开价格范围不是平台最终金额保证。暂停和取消只阻止后续执行，已提交的请求可能继续完成或计费。失败及结果未知不自动重复提交，请先在原任务中查询或找回结果。

待核对时点击“前往原有页面处理”，仍在原文、剧本、资产、片段和审片页确认，再返回生成任务点击“检查并继续”。没有额外的人工验收画布节点；打开看过不自动记为审图/审片通过，使用原有确认和选用按钮即可。首片放行和五层核对继续沿用已有操作。

支持 MCP 的外部 Agent 可查询项目、读取价格与额度、启动/暂停/继续/取消流程、保存原文草稿和视觉计划。MCP 不开放预算确认、锁稿或人工放行工具。先启动软件，再按包内 [Agent接入说明.md](Agent接入说明.md) 配置 MCP；工作流进度与记录保存在本机数据库，重启保留，未知结果不会自动重试。

## 导出预检提示怎么处理

“正式成片导出预检”核对正式验收；上方“精剪草稿”可以先把已选素材送入剪映继续编辑，保留现有验收标记。

- 技术检查待完成：点“前往画布检查文件与逐句审片”，在对应视频版本点击“检查文件/黑帧/冻结”。检查与当前文件的大小和修改时间绑定；文件换了需重查。
- 对白/OS待核对：在同一视频的“逐项审片核对”中听验原句和角色声线，填实测时间，再使用原有“标为成功片段”。有音轨或曾选用不等于每句已经核验。
- 高光预告待选择：常规漫剧默认首集需要高光；在导出页从现有正片勾选高光并保存，或导入预告MP4。可通过本集预告设置明确改为不添加。
- 参考资产待绑定：真正出镜的人物、场景和道具仍需绑定。来信发件人、纸上署名/落款和台词中的未来目的地不会仅因名字出现就要求新增画面资产；含糊情形仍须人工核对。

程序不会用这些操作覆盖锁定剧情、自动选用新版本或替用户认定声音合格。

## MP4 自动合成

在“剪映导出”页完成正式导出预检后，点击“合成并导出 MP4”。软件读取已选视频，按片段编号排列，将已选高光放在开头，执行画布设置的倍速，保留原声；不同素材尺寸会适配成统一画布，不裁掉画面。对白默认 1.15 倍、动作默认 1.5 倍，可在画布逐段改为 1 倍或其它值。

成片保存为新的 MP4，不覆盖源视频。导出页提供播放器、下载及本机路径。合成期间改动项目或替换素材会使本次导出停止，重新核对后再导出。MP4 使用正式验收要求，精剪草稿的待验收模式不能绕过 MP4 预检。Agent 流程在最终确认后自动合成 MP4，并另外保存剪映草稿；若草稿目录不可写，已有 MP4 仍保留。

宣传演示主题为“从小说原文或剧本，一键启动自动制作，核对后导出成片”。一键启动指串联制作流程；剧情、审图、审片及费用确认仍需要用户处理。宣传内容不涉及模型平台或接口配置。
