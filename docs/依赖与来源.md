# 依赖与来源记录（本机开发版）

本项目的业务代码、剧情合同、任务队列、模型协议和剪映草稿适配器在新目录中编写。画布复用 Infinite Canvas 组件，详细来源见 [PROVENANCE](../third-party/infinite-canvas/PROVENANCE.md)，作者 basketikun，MIT；保留原作者入口与许可文本。原创部分采用根目录 LICENSE 中的Apache-2.0 开源许可，第三方部分适用各自的许可。

| 用途 | 依赖 | 本机版本 | 包声明许可证 |
| --- | --- | --- | --- |
| TypeScript 编译 | `typescript` | 6.0.3 | Apache-2.0 |
| 开发构建 | `vite` | 7.3.6 | MIT |
| 开发时运行 TS | `tsx` | 4.23.15 | MIT |
| Node 类型 | `@types/node` | 24.19.0 | MIT |
| 图片格式转换与动作板栅格化 | `sharp` | 0.35.5 | Apache-2.0 |

前四项用于开发与构建；`sharp` 是图片/视频适配器的运行库。版本以 `package-lock.json` 为准。第三方包自己的许可证不会把本项目新写的业务代码变成 MIT 代码；发行时仍须按实际打包内容履行第三方许可义务。

新软件直连路径由本项目的 `adapters/direct-*.mjs` 和 `server/direct-provider.ts` 实现，只依赖用户单独配置的模型 API，不依赖木木工坊进程或数据库。旧 `adapters/mumu-*.mjs` 联动路径仍保留供已有项目过渡；启用该路径才依赖木木工坊后端。木木工坊属于单独的软件和许可范围，不是新软件框架。

FFmpeg/FFprobe 用于视频探测和超分前后处理。此次依赖安装型试用包不捆绑 Node、FFmpeg、sharp/libvips 原生运行库，由使用者独立安装。其他历史便携候选的分发核验状态见 docs/third-party-release/DISTRIBUTION-STATUS.md，不作为本次下载包。Real-ESRGAN 工具和模型不随包分发。

特效数据来源和迁移范围见 [`catalog/PROVENANCE.md`](../catalog/PROVENANCE.md)。剪映草稿 JSON 为适配本机格式而独立编写；剪映本身和格式不属于本项目。
