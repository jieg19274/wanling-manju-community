# 万灵漫剧社区版安装说明

## Windows 安装器

1. 从官方 Releases 下载 `wanling-manju-0.4.24-community-windows-x64.msi`。
2. 双击安装器，按提示安装。安装在当前用户的 `%LOCALAPPDATA%\WanlingManjuCommunity`，不修改系统 PATH。
3. 打开桌面或开始菜单中的“万灵漫剧 社区版”。首次启动显示准备进度，联网从 Node.js 官方、npm 官方仓库和 FFmpeg 官方下载页推荐的 Gyan 构建仓库获取依赖。下载校验失败时停止，不关闭 TLS 校验、不切换未知镜像。
4. 准备完成后浏览器打开 `http://127.0.0.1:5780`。保持启动窗口开启，关闭窗口停止服务。重复打开同一安装会复用现有服务；端口被其它安装占用时提示处理，不停止其它软件。
5. 打开内置演示项目，可直接查看素材和播放样片。制作自己的内容时，在设置中填写自己的模型密钥，并按界面确认生成费用。

首次准备约下载 170 MB，预留至少 1 GB 空间。运行依赖放在软件目录的 `tools/` 和 `node_modules/`，随下载保留原始 LICENSE、README 等许可材料。没有管理员权限也可使用本机工作台；Windows 安装策略如限制 MSI，请使用下面的 ZIP 方式。

网络失败后可再次打开快捷方式继续。需要代理时按 Windows 网络环境配置；不要求关闭安全软件或证书校验。运行日志保存在 `runtime/logs/`。未数字签名的社区安装器可能显示未知发布者；请核对官方来源及 Releases 的 SHA256SUMS.txt。

## ZIP 文件夹版

下载社区版 ZIP，完整解压到自己的可写目录，双击“启动社区版.cmd”。使用相同的官方依赖准备流程。不要直接在压缩包里运行。没有 MSI 安装时，可双击“创建社区版快捷方式.cmd”。移动目录后重新创建快捷方式。

## 数据、更新和卸载

项目、模型设置与草稿位于软件目录的 `runtime/`。新版安装前先关闭软件，并备份自己的 `runtime/`。社区版默认不连接旧发行版的自动更新服务，使用本仓库 Releases 获取更新。

Windows 设置中的应用列表可以卸载 MSI 安装的程序。卸载保留运行后生成的 `runtime/`、下载的 `tools/` 和 `node_modules/`，避免误删作品；不再需要时，确认备份后自行删除剩余软件目录。

## 功能边界

软件按 Apache-2.0 发布，第三方许可见 THIRD_PARTY_NOTICES.md。模型账户、原文、素材和剪映本身按各自条款使用。真实生成会产生供应商费用；内置演示不会自动调用模型。

Real-ESRGAN 和模型不随包提供；真超分仍需自行配置受支持的工具。Windows 安装器的安装、卸载和启动会针对发布候选独立验收，不把源码测试当作安装器验收。
