# 万灵漫剧：从文字到成片

把小说原文或剧本放进万灵漫剧，选择本次交付再启动制作。新项目默认完成分镜生产包；明确选择成片后，才进入视频生成、实际审片和 MP4 合成。先核对完整原文、高光与锁定剧本的原文覆盖，再制作资产与参考图。

v0.4.15 起，此教程与官方接管技能随签名程序包自动更新。设置 → 交给 Agent 制作提供最新版教程与技能下载。

首次启动已带有“演示项目 · 从文字到成片”。项目首页可以直接播放演示样片，点击“查看制作画布”查看制作内容。示例保存在本机，观看和查看不会产生生成费用。

1. **查看原文与高光。** 进入画布的“原文与高光”，查看完整原文、章节范围和高光剧情，再到“正式剧本”查看锁定的事件、人物反应与对白。
2. **查看角色与场景。** 在资产节点打开角色图、人物大头照及场景图；放大图片，查看它们怎样关联到分镜。
   人物制作统一使用完整四视图＋大头照（正面全身、90°侧面全身、背面全身、正面大头近照），实际审图后直接绑定整张参考。独立全身照、独立头图及裁切入口已移除。局部修正可在“资产与状态”点原图的“以此图返修”，输出仍为完整四视图；预览中会显示实际原图与费用。
3. **查看分镜。** 点击分镜节点，查看子镜的动作、时长、对白安排和末帧衔接。锁定剧本决定剧情，分镜细化拍摄方式。
4. **查看视频。** 点击视频节点播放，双击放大；在候选工作台比较不同版本，不满意可以重新生成，再明确选择需要使用的版本。
5. **核对并导出。** 使用现有的剧情核对和逐项审片，完成确认后在“剪映导出”中选择“合成并导出 MP4”。软件按片段顺序合成并保留原声，也能另存剪映草稿。
6. **制作自己的故事。** 新建项目、选择画面风格和格式，导入自己的小说或剧本。在 Agent 面板预览工作流与预算，确认后启动；遇到需要核对的步骤，在原页面完成即可继续。

三个默认模型分别完成了本示例的文本、图片和视频生成。演示项目保留原文、高光、正式剧本、资产、分镜、最终提示词、原始视频与实机界面合成的演示样片，方便逐步查看。
