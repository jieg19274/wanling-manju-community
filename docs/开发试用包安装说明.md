# Windows开发试用包：安装与验收

这是需要安装运行依赖的 Windows x64 文件夹版，适合小范围本地试用。包内包含公开演示项目、演示样片及已授权的风格素材与特效；不含制作人的账户、密钥、私人项目、账本或付费授权。

1. 自行从Node.js官方渠道安装Windows x64 Node.js 24，确认node及npm可用。
2. 解压到自己的可写文件夹，在该目录打开PowerShell。
3. 双击“准备试用环境.cmd”安装运行依赖，或在 PowerShell 中执行：

   `npm ci --omit=dev --include=optional --registry=https://registry.npmjs.org/`

   sharp固定0.35.5，传递依赖版本、官方npm地址及完整性哈希在lock中锁定。此步骤由使用者联网获取依赖，可能下载原生二进制并执行npm正常安装脚本；不是本包捆绑，也不是我们替使用者接受协议。不要省略optional依赖。TLS、权限或网络错误应停止排查，不关闭证书校验、不换不明镜像。本包不自动安装或提升权限。
4. 执行`npm start`或双击“启动试用.cmd”，就绪后自动在默认浏览器打开软件界面。保持启动窗口开启，关闭窗口停止服务。重复点击会打开同一份软件的现有界面；其它程序占用端口时退出，不停止其它程序。
5. 首次运行在本包 runtime 目录建立独立数据，自动加入“演示项目 · 从文字到成片”。无需密钥即可播放演示样片并查看画布。文本、图片和视频默认模型已经预置，新项目自动继承。制作自己的内容时，在设置中填写自己的密钥；真实生成会收费，核对费用及实际发送内容后再确认。

Node、FFmpeg/ffprobe、Real-ESRGAN与模型均未附带或自动安装。视频探测、头参和剪映导出需要本地FFmpeg；真超分另需受支持Real-ESRGAN。缺依赖时相关功能不可声称可用，不用resize冒充超分。

没有 FFmpeg 时，可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)选择 Windows 构建，或在 Windows 终端中使用 `winget install --id Gyan.FFmpeg.Essentials --exact --source winget`，按安装器提示完成后重新打开启动窗口。仅查看内置演示样片不需要 FFmpeg；制作和导出新视频需要它。

## 验收边界

本包的启动、模型默认值、演示素材和桌面/手机页面检查见包内验收记录。不同电脑的权限、网络和剪映环境仍需在试用时确认。它是本地单用户试用版，不能作为公网多用户服务。

预置模型：文本 `claude-opus-5-5`，图片 `gpt-image-2.5-sunburst`，视频 `专享sd2.5(30图10音/4-30秒/720p)`。可在设置中改选，已有项目保留自己的选择。演示教程见“从文字到成片教程.md”，密钥添加步骤见“功能使用说明.md”。
