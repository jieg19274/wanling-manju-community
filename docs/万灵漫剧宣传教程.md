# 从文字到成片：万灵漫剧制作教程

将小说原文或剧本放入万灵漫剧，选择生产包或成片，在画布上核对结果。新项目默认交付分镜生产包；选择成片才会进入视频生成、实际听看审片，再导出带原声的 MP4。

1. **建立项目。** 在首页新建项目，先设置画面风格、比例和生成模型。将小说全文放入“原文自动分集”，预览分集后创建；已有剧本也可按分集导入。
2. **启动制作流程。** 进入本集的“生成任务”，选择“本次交付”，设置提交次数上限，点击“启动本集流程”。次数上限控制请求数量，费用按模型与实际用量结算。流程从当前进度继续，先核对原文、高光、正式剧本与原文覆盖，再制作资产、参考图和分镜；成片模式才会生成视频。
3. **核对剧情。** 查看高光报告与剧本候选，保留原文依据、对白及人物反应，确认后锁定正式剧本。流程停在待核对步骤时，直接前往原有页面处理，再点“检查并继续”。
   人物统一使用完整四视图＋大头照，实际核验后直接绑定整张图，保留全部视角固定人物一致性；局部错误以原图返修完整四视图。独立全身照、头图和裁切流程已移除。
4. **在画布上查看素材。** 点击图片放大，视频可大窗播放。参考图和视频生成新候选后，比较、核对并明确选用。需要重做时从节点“信息”进入生成工作台，保留已有版本。
5. **完成审片。** 检查当前文件、逐句听验对白与角色声线，并完成五层核对。需要高光预告时，从已选正片挑选起点和长度；先核对内容，再保存高光选择。
6. **导出成片。** 通过正式预检后，在导出页点击“合成并导出 MP4”。软件保留原声、执行逐段倍速、按顺序合成；完成后可播放和下载。Agent 最后一步也会合成 MP4，并另外保存剪映草稿，方便继续精剪。

一键启动会串联制作任务；剧情、候选选用、审片及费用确认仍由用户处理。生成结果需要核对，完成查看本身不会自动标为通过。

## 30 秒宣传片

主题：让故事，从文字走向画面。

画面：深蓝与青色的创作工作台，演示员“小灵”导入文字，画面转为剧情、资产、分镜与视频的制作链；最后展示成片。软件操作画面使用实际界面，创意镜头不冒充软件录屏。

台词：

> 小说原文或剧本，放进万灵漫剧，一键启动制作。剧情、资产、分镜、视频，按流程生成。画布里查看、比较，不满意就重做。核对通过，自动合成带原声的成片。让故事，从文字走向画面。

声音由视频模型原生生成，后期文字仅辅助说明。实际宣传素材不出现模型平台、接口、密钥或计费后台。

## 验证记录

已实际完成原文高光提取、剧本候选、资产提取、角色和场景参考图生成，并提交真实视频生成。第一版因对白重复保留为未通过版本；修订版把原台词按句分配到独立声音窗口，剧情和文字保持不变。成片须核对完整对白、人物声线和实际画面后放行。

生成候选、比较、选用、审片和导出是独立步骤。点击查看不会自动代替审片确认；结果不满意时保留旧版本，在原节点准备新候选。
