# 剪映导出

“导出本集剪映草稿”和“按集数批量导出”是生产导出，保留完整验收门禁。“精剪草稿（保留验收状态）”可将明确选择的待验收候选送去编辑，但不改变审核或采用状态；已采用片段必须使用已采用版本，不能导出判废或撤回候选。

精剪入口默认使用同页超分选项和画布逐段倍速：有速度覆盖时使用覆盖值，否则普通片段1.15倍、动作片段1.5倍。仅显式选“原速备份”才固定1倍且不超分。勾选真实2倍超分时调用本机Real-ESRGAN `realesr-animevideov3-x2`模型；勾选仅低于1080p时，高于阈值的素材复用原文件。不会用普通resize替代。超分期间复制原音频，不分离音轨。

每次新建独立草稿并复制媒体，不覆盖旧草稿；没有自动字幕、浮签文字或系统提示文字轨道，视频内已有的烧录文字仍在。字幕由用户在剪映识别。精剪默认不额外加高光，生产导出按本集已保存的高光配置执行。

草稿目录由启动环境`MANJU_JIANYING_DRAFTS_DIR`决定；5698隔离实例默认在E盘`.test-temp/startup-20260930-140522/drafts`。该目录并不自动成为剪映发现目录。需要登记到本机剪映时，使用同一内置导出函数的`installedDestination`选项，在剪映关闭时新建到其既有目录并追加登记，保留原索引备份。受限执行环境写C盘需要相应权限；失败不能当作导出成功。

2026-09-30第一次EP1/EP2原速精剪备份没有使用之后用户截图指定的超分与倍速；保留这些草稿供用户继续精剪，纠正版另存，不覆盖。
