# 万灵漫剧 Agent 接入

模型切换后先重新读取 context，核对 `connection` 的安装目录、数据目录、软件版本与 `project.id`。工作流历史报错属于上次执行；`modelRequests` 给出最近请求快照模型、实际 HTTP 模型、状态和服务商请求 ID。没有新增记录不能报告成“新模型仍调用旧模型”，收到未知结果也不能自动重提。

旧版已有剧本通过 `context.scriptReadiness` 查看每集缺项。保留已有节点和全部内容，完整读原文后确认阅读，再导入或依据原文补写高光报告并核对；补齐逐字依据后锁定现有稿。外部 Agent 可用现有 `episode.update.highlightReport` 与核验动作处理，不必重新生成 40 集剧本。原文缺失或剧情有实际缺漏时报告具体集/节点，不自动放行。Agent 任务页列出待补核对的已有剧本。

v0.4.22 模型配置：当前项目的 `textModel/imageModel/videoModel` 是实际提交的模型；软件设置中的默认选择用于新项目。`readiness?projectId=…` 与 dashboard 显示本项目实际模型和不同的默认模型。客户可在 Agent 准备检查点击“本项目改用…”，或在项目概览的“本项目生成模型”逐项切换。模型切换后先重新读取 context；原有任务授权仍按已保存的配置核验，不能借切换模型重置额度。

提示词版本管理已提供 `segment.prompt.unselect/archive/restore` 与 `episode.prompts.manage`。旧版可停用并退出当前列表，完整正文及已生成视频来源仍保留；停用版不能新选用，恢复不自动选用或放行。`segment.writePrompt` 可写入并选用完整新版，附 `archivePrevious:true` 可同时停用原选版。

同分集批量处理使用 `episode.prompts.manage`：`operation` 为 `archive/restore/unselect/select/replace`；`entries` 指定每项的 `segmentId`，管理现有版本时附 `artifactId`，写入新版时附完整 `content`。可附刚读取的 `expectedPromptId` 防止旧状态覆盖；未选用为 `null`。`select/replace` 可传 `archivePrevious:true`。先验证全部目标及正式内容，再一次提交；一项失败整批不改。Agent仍使用稳定 `requestId` 和对应项目 `expectedHash`，重复原请求不会重复写入。

软件制作画布与版本表的“提示词管理”支持全文写入、取消选用、勾选批量换选／停用，以及历史恢复。不要直接删除数据库中的提示词来源，也不要把“已停用”报告为“物理删除”。没有自动提交视频或撤销旧片验收。

v0.4.15 起，官方技能与教程位于 `dist-server/bundled`，随签名程序包自动更新。连接接口返回当前软件版本及最新版技能、教程路径；连接后先读取这份技能。设置页可以下载最新版技能 ZIP 与新手教程。已经导入其他客户端的技能副本需要重新下载导入，软件不会覆盖用户在外部客户端编辑的技能。

锁定正式剧本后，先完成逐节点原文语义与高光覆盖核对，再提取资产和生成参考图。技术检查只核验媒体文件，不代替实际听看视频和逐句审片。生产包流程明确保存交付目标，视频额度为零；常用界面的次数上限不等于金额预算。

在软件“全局设置 → 交给 Agent 制作”选择客户端，下载官方技能 ZIP。TRAE 在“技能与命令”创建全局技能并导入 ZIP；WorkBuddy 在技能管理中上传 ZIP；Codex 解压技能文件夹至自己的 `.codex/skills`。免安装包也提供“安装Codex接管技能.cmd”和“导出Agent接管技能.cmd”。重新打开客户端后使用技能。

技能的本机入口会自动启动或复用软件，无需每次先打开界面。它核对安装目录和数据目录，端口连接到其他实例时会明确停止。软件搬家后重新下载或安装技能。仅拖入快捷方式能否识别取决于客户端读取本机文件的能力；`AGENT_START.md` 和复制接管说明提供明确入口。

默认规则为每片段30秒、原文1–3章一集，Agent 阅读完整原文后选自然剧情边界，默认交付生产包。软件设置可保存新项目偏好，已有项目保留原规则。内容过载拆段，不能删剧情或声音。

MCP 配置使用本机自带 Node 和 `scripts/agent-mcp.mjs`。安装脚本在 `agent-exports` 或指定技能目录生成配置 JSON；按客户端界面导入。源码工程可运行 `npm run mcp`，默认5698端口；免安装包固定5780端口。旧 `trial-mcp.mjs` 入口仍兼容。

主要工具：`agent_connect` 获取默认规则与接口合同；`agent_readiness` 检查本机配置；`agent_dashboard` 轻量读取进度、剩余额度和交付文件；`agent_create_project` 幂等创建项目；`agent_context` 读取完整原文、最新状态哈希、五层文本、素材路径与记录；`agent_task` 保存本次任务集数、交付目标和额度；`agent_command` 执行动作、接管、继续、暂停和撤回。没有 MCP 时，技能内 `scripts/run.mjs` 支持相同 CLI 流程，参数写入 JSON 文件。

人物参考统一使用完整四视图＋大头照（横向正面全身、90°侧面全身、背面全身、正面大头近照）。Agent实际看图并审查后，直接显式绑定整张图；全部视角作为同一角色的一个参考传给视频模型。独立全身照、独立头图及裁切入口已移除，历史照片只作为记录保存。返修输出仍为完整四视图；原图或参考变化时禁止沿用旧费用确认。没有看片能力时应等待实际核验。

项目里的“Agent 任务”页统一显示当前步骤、待处理原因、文本／图片／视频剩余提交次数、Agent核验记录和交付位置。暂停同时锁住任务授权及其关联流程，重启后仍保留；恢复须在软件面板操作，沿用剩余额度。外部Agent随后继续运行，才能完成内容核验和下一步制作。已提交请求可能在暂停后返回结果，不自动取消远端扣费。配置检查只验证本机条件，不声称收费模型已连接成功。费用预留和实际扣费分开显示。

每次修改都带最新 `expectedHash` 和稳定 `requestId`。同一请求重复返回已有结果，不重复建项目或预约生成。草稿可先准备；核验须关联本次任务并写具体依据，完整阅读还须覆盖完整原文字数和哈希。审核身份记录为 Agent；不能冒充用户，也不能用结构检查代替实际审图、审片。正式剧本锁定后，下游遵循原有不可删改规则。

付费调用先预约本次任务额度。任务有效24小时，只覆盖指定集数和模型配置。次数上限与金额上限分开；金额无法确认或超过上限时停止。未知费用须有明确接受；结果未知仍计入提交次数，先找回原任务，不自动重提。默认生产包任务禁止视频生成；视频交付需明确任务范围和额度。旧 `start_workflow` 仍使用软件页面逐步确认模式。

生产包导出后结束；视频流程完成首片验证和逐片听看后，才合成保留角色声音的 MP4，并另存剪映草稿。文件、进度、任务 ID 和未完成项应如实交付。
